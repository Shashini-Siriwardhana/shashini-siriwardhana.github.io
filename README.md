# Shashini Siriwardhana — Portfolio

A responsive static portfolio website built from Shashini's CV and public GitHub projects.

## Run locally

No build step is required.

1. Open `index.html` directly in your browser, or
2. Run a simple local server:
   - Python: `python3 -m http.server 8000`
   - Then visit `http://localhost:8000`

## Deploy with GitHub Pages

1. Create a new public repository, e.g. `portfolio`.
2. Add all files from this folder to the repository root.
3. Commit and push.
4. In GitHub: **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`.
7. Save.

You can also name the repository `Shashini-Siriwardhana.github.io` to publish it at the standard GitHub Pages user-site URL.

## Customize

- Main content: `index.html`
- Colors/layout: `styles.css`
- Theme/reveal interaction: `script.js`
- CV: `assets/Shashini_Siriwardhana_CV.pdf`
